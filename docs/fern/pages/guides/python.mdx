The usual in-process stack is:

```python
from bcg import BCG, BCGMemory, BCGRunner, LLMClient

memory = BCGMemory(graph=BCG())
runner = BCGRunner(
    memory=memory,
    llm=LLMClient(),
    backend="api_based",
)
```

## Process a complete trajectory

```python
result = await runner.observe_trajectory(
    [
        {"role": "user", "content": "The deployment failed twice."},
        {"role": "assistant", "content": "We should inspect the rollback logs."},
    ],
    run_id="deployment-review",
)
```

## Stream turns explicitly

```python
runner.begin_belief_run(run_id="support-case")
runner.start_session("chat-1", date="2026-08-11")

await runner.observe_turn("user", "The customer reports repeated timeouts.")
await runner.observe_turn("assistant", "We should inspect gateway saturation.")

await runner.end_session()
result = await runner.finalize()
```

## Read the result

```python
for item in result.graph.beliefs():
    print(item.id, item.belief or item.decision, item.confidence)

context = result.graph.to_memory_dict()
```
