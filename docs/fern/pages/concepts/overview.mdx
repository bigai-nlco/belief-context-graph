BCG models the knowledge state accumulated from an agent trajectory. The code uses precise graph terms, but most users only need the concepts below.

| User-facing concept | BCG field or type | What it means |
|---|---|---|
| **Stored knowledge** | belief node | A proposition retained by the system |
| **Decision** | decision node | An action or conclusion retained in the same graph |
| **Source** | source + evidence | Where the proposition came from |
| **Confidence** | confidence fields | How strongly the current graph supports the proposition |
| **Connection** | relation | How two pieces of knowledge affect or qualify each other |
| **Duplicate handling** | merge | How repeated or equivalent knowledge is canonicalized |
| **Conversation history** | session / turn metadata | When and where knowledge was formed |
| **Context selection** | memory context | What graph state is returned to the next model call |
