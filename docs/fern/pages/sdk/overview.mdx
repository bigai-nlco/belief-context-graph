## Recommended imports

```python
from bcg import (
    BCG,
    BCGMemory,
    BCGRunner,
    BCGSettings,
    LLMClient,
    load_settings,
)
```

## SDK Reference vs HTTP API

Use **SDK Reference** when your Python process directly imports BCG.

Use **HTTP API** when another process or another language talks to a running BCG construction service over `/turn`, `/graph`, `/finalize`, and related endpoints.

The sidebars intentionally look similar—resource heading, then child operations—but the contract being documented is different.
