BCG's Python SDK is an **in-process library API**. This reference uses API-style
`GET`, `POST`, `PATCH`, and `DELETE` badges to make methods easier to scan, similar
to an HTTP API reference. The badges describe **method behavior only**; these SDK
paths are not network endpoints.

## Recommended imports

```python
from bcg import (
    BCG,
    BCGMemory,
    BCGRunner,
    BCGSettings,
    LLMClient,
    load_settings,
)
```

## SDK Reference vs HTTP API

Use **SDK Reference** when your Python process directly imports BCG.

Use **HTTP API** when another process or another language talks to a running BCG
construction service over `/turn`, `/graph`, `/finalize`, and related endpoints.
