## Load settings

```python
from bcg import load_settings

settings, sources = load_settings(
    explicit="./config/prod.yaml",
    cli_overrides={"backend": "unified"},
)
```

Default precedence is:

```text
CLI overrides
→ explicit config
→ BCG_CONFIG
→ project bcg.yaml
→ ~/.bcg/config.yaml
→ packaged defaults
```

Top-level `BCGSettings` groups include:

```text
schema_version
backend
model_key
embedding_key
server
models
pipeline
runner
```
