---
title: Low-level Graph Operations
description: Insert fully formed BCGNode or BCGEdge wrappers when you need graph-level
  control.
icon: wrench
---

Most applications should use typed belief and relation methods. The low-level methods are useful when you are implementing graph infrastructure itself.

## Add a graph node

```python
from bcg.core.graph import BCGNode

node = BCGNode(name="Custom node")
await graph.add_node(node)
```

```python
await graph.add_node(node: BCGNode) -> None
```

## Add a graph edge

```python
from bcg.core.graph import BCGEdge

edge = BCGEdge(source=source_uuid, target=target_uuid)
await graph.add_edge(edge)
```

```python
await graph.add_edge(edge: BCGEdge) -> None
```

<Tip>
Prefer `add_belief()` and typed relation methods unless your integration truly needs graph-wrapper control.
</Tip>
