---
title: Create and Update Graph Knowledge
description: Add, allocate, update, and remove belief or decision payloads in BCG.
icon: pen-to-square
---

Use these methods when your application is directly managing graph items.

## `BCG.add_belief()`

```python
from bcg import BCG
from bcg.core.graph import BeliefPayload, BeliefSource

graph = BCG()
source = BeliefSource(
    type="trajectory",
    role="user",
    trajectory_index=0,
    segment_index=0,
    segment_type="message",
)

item = BeliefPayload(
    id=graph.allocate_belief_id(),
    belief="The deployment failed after the upgrade.",
    node_type="belief",
    stance="asserted",
    role="user",
    layer="io",
    source=source,
)

node = graph.add_belief(item)
```

```python
graph.add_belief(belief: BeliefPayload) -> BCGNode
```

## `BCG.next_belief_id` and `BCG.allocate_belief_id()`

```python
next_id = graph.next_belief_id
reserved_id = graph.allocate_belief_id()
```

<Warning>
`next_belief_id` is a property in the current code. Do not call `graph.next_belief_id()`.
</Warning>

## `BCG.update_belief()`

```python
item = graph.beliefs()[0].model_copy(update={"confidence": 0.9})
graph.update_belief(item)
```

```python
graph.update_belief(belief: BeliefPayload | dict[str, Any]) -> None
```

## `BCG.remove_belief()`

```python
removed = graph.remove_belief(12)
```

```python
graph.remove_belief(
    belief_id: int,
    *,
    drop_edges: bool = True,
) -> BCGNode | None
```

Keep the default `drop_edges=True` for normal application use so the graph does not retain incident edges pointing at a removed node.
