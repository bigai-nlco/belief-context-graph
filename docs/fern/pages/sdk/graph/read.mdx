## List stored knowledge

```python
typed_items = graph.beliefs()

for item in typed_items:
    print(item.id, item.node_type, item.belief or item.decision)
```

```python
graph.beliefs() -> list[BeliefPayload]
graph.belief_nodes() -> list[BCGNode]
graph.belief_dicts() -> list[dict[str, Any]]
```

`beliefs()` returns typed `BeliefPayload` objects. Use `belief_dicts()` only when you explicitly need JSON-compatible dictionaries.

<Info>
Despite the compatibility method name, `beliefs()` can include both `belief` and `decision` nodes.
</Info>

## Find one graph node

```python
node = graph.node_for_belief_id(12)
```

```python
graph.node_for_belief_id(belief_id: int) -> BCGNode | None
```
