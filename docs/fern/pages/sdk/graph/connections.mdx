---
title: Connections and Relation Maintenance
description: Add, list, and remap typed relationships between graph items.
icon: share-nodes
---

Primary current relation types are:

```text
depends_on
supplements
contradicts
```

## Add one connection

```python
from bcg.core.graph import RelationPayload

relation = RelationPayload(
    from_id=1,
    to_id=0,
    type="depends_on",
    note="The decision depends on the outage observation.",
)

edge = graph.add_relation_by_ids(relation)
```

```python
graph.add_relation(
    relation: RelationPayload,
    *,
    source_uuid: str,
    target_uuid: str,
) -> BCGEdge

graph.add_relation_by_ids(
    relation: RelationPayload,
) -> BCGEdge | None
```

## Add connections in bulk

```python
added = graph.add_relations([
    {
        "from_id": 1,
        "to_id": 0,
        "type": "depends_on",
        "note": "Decision depends on the observed outage.",
    }
])
```

```python
graph.add_relations(relations: list[dict[str, Any]]) -> int
```

## List connections

```python
all_relations = graph.relations()
conflicts = graph.relations("contradicts")
json_relations = graph.relation_dicts()
```

## Remap after canonicalization

```python
summary = graph.remap_relations({
    12: 4,
    13: 4,
})
```

```python
graph.remap_relations(mapping: dict[int, int]) -> dict[str, Any]
```

Use remapping for merge/canonicalization maintenance rather than ordinary read/write application flow.
