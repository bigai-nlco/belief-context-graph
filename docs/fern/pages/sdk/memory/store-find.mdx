## `BCGMemory.observe()`

Use `observe()` when your application already knows the proposition to store and does not need LLM extraction.

```python
observation = memory.observe(
    source_type="manual",
    content="The production region is us-west-2.",
    actor={"role": "system"},
    observed_at="2026-08-11",
    metadata={"source_id": "deployment-config"},
)
```

```python
memory.observe(
    *,
    source_type: str,
    content: str,
    actor: dict[str, Any] | None = None,
    observed_at: str | None = None,
    metadata: dict[str, Any] | None = None,
) -> MemoryObservation
```

It creates one asserted belief in the `io` layer, records manual source/evidence information, and does not call an LLM.

## `BCGMemory.believe()`

```python
matches = memory.believe("outage", max_results=5)

for item in matches:
    print(item.id, item.belief, item.confidence)
```

```python
memory.believe(target: str, **kwargs: Any) -> list[BeliefPayload]
```

The current implementation is a case-insensitive substring match against belief text. It returns typed `BeliefPayload` objects, not dictionaries.
