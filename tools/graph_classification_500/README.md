# Reproducing the 500-case BCG classifier study

Open `REPORT.md` in the result directory first. No key is needed to inspect any of the evidence, scores, requests or responses.

**Offline check (only standard Python):** from the extracted result directory run `python3 verify_release.py .`. This independently recomputes 24 arm/split metrics from the item CSVs and checks the original source/gold SHA-256 locks. Raw response records include only request bodies, never provider authentication headers.

**Re-score in this repository:** `.venv/bin/python -B -m tools.graph_classification_500.analyze`. This includes 3,000 paired cluster-bootstrap resamples; it reads no API key. Classification uses the existing graph stack and original candidate-stage replay; this is not a new agent or a production default. The package includes snapshots of those dependencies plus a fingerprint. In a clean checkout overlay matching code and the frozen results under the repository layout; the original source graph directories are required only for rebuilding candidates or replaying whole stages. For the old regression those original case/context files live under `results/graph-classification-bench-20261118/dataset`.

**Study sequence:** `data freeze` mines original logs and refuses to overwrite cases; `labels` seals the independently authored references; `controls v4/v5/v7` checks unchanged candidates and changed question definitions; `run dev <arms>` runs the corp gateway; `calibrate` fits v6 via grouped out-of-fold development predictions; `grade select` locks a version before test access. `run test <arms>` and `run challenge <fixed arms>` require the lock. `reuse` applies another decoder only to identical raw responses. `repair` retains the initial attempts and reuses exact matching HTTP request bodies; `status_diag` independently measures the role-to-status eligibility gate. An immutable original selection record plus a separate transport-fix confirmation are included. On an already frozen experiment use the offline checks, not a new selection/overwrite. Never synthesize missing alignments or treat an unreported charge as zero.

The v6 fitted multipliers are in `configs/v6.json`; `run.choose` applies them only to a single candidate's Decisions probabilities. `run.decoded` leaves the provider response and graph confidence untouched. Experiments are not enabled on the live graph server.
