# BCG graph classification: preregistered protocol, 2026-11-19

Population: source-grounded classification decisions, not 500 independent agent tasks. Draw exactly 250 development and 250 holdout cases (100 nodes, 60 possible parent links, 90 directed semantic pairs per split). Stratify before annotation by source, difficulty cues and task. Exclude old benchmark windows, literal statements/pairs and reversed duplicates. Use disjoint original tasks; use new benchmarks only as held-out tests, not to select variants.

Independently assign reference labels from the shown, pre-decision material; do not use historical classifier answers or downstream final graph labels. Annotator: Codex, one blind pass; rationales and uncertainty stay visible to reviewers, no claim of human or multi-rater consensus. Nodes can have multiple applicable fields. Reported speech/intent and verified external facts are different claims. A final recommendation can be a decision, while a thinking-only candidate cannot. Parent links must be in the given direction; looking up material is not itself a separately checkable output. Edges are directional, between the actual endpoint assertions. Missing context is not negative evidence: mark insufficient/ambiguous fields. Do not construct positive contradictions merely because dates or numbers differ. Exclude individual ambiguous fields, not whole cases, from primary scoring. Publish all labels, agreement on ambiguous fields separately, and split-specific counts.

Compare joint graph-model extraction and classification (native), GPT Chat with fixed candidates, shipping Decisions v1 and the old best v4. Frozen candidates isolate classification; the native path additionally needs to propose/find a candidate. Do not describe these as equivalent inputs. Optimize at most three new versions on development only, without case identifiers, gold or predicted labels in model inputs. For new evidence or changed instructions, include an identical-payload GPT Chat control for the winning version. Pick among Decision versions by development three-group-balanced macro-F1 (mean of field macro-F1 within node, parent and edge groups, then equal-weight mean of groups). Use group-balanced F1 unrounded, then fewer input+output tokens if tied. Lock choices, code and configuration before looking at held-out model output. Keep old 100 regression separate. No user-facing defaults change.

Secondary measures: label support, per-field accuracy and macro-F1, per-class precision/recall, missing alignment, proposal coverage, failures, task-cluster paired bootstrap uncertainty, per-call input/output tokens, disclosed provider charges and missing cost coverage. Missing predictions count as errors on otherwise scorable fields. Compare a locked optimized pipeline against the native pipeline on the same original windows; native vs fixed, aligned-only vs end-to-end-window denominators shown separately. No full Agent outcome/cost claim. Distinguish natural main set, rare-class diagnostics, production replay and regression; do not pool or tune on the latter three.
