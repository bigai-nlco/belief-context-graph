页面中的常用术语
Case
一道题在一种模式下的完整运行记录。
Belief
Graph 中记录的一条事实、假设或结论，通常带有来源与 confidence。
Relation
belief 之间的关系。例如 B31 depends_on B28 表示 B31 依赖 B28。
Context
某次模型调用的输入。本页「每轮 Belief 注入情况」展示其中的系统内容或 Graph 注入记录。
关键过程
选定的一次行动或决策，包含来源、实际行为和后续影响。

完成本步后：任务目标与结果已记录，下一步查看影响结果的行动。

先在第 1 步导入文件或打开练习 Case。

沿轨迹记录关键过程

操作位置：左侧「运行轨迹」 → 记录旁的「引用为关键过程」

  1. 沿运行轨迹定位有分析价值的行动，重点查看 BCG 本应帮助复用证据、减少重复搜索或发现缺口，却没有发挥作用的地方。
  2. 点击「引用为关键过程」，自动保存位置、原文摘录和所属 Agent。也可先选中一段文字，再点击引用。
  3. 填写三项：「BCG 应发挥的作用」「实际发生的情况」「影响与改进线索」。再选择归因环节和证据强度。每项用一两句话即可。
  4. 需要进一步定位问题时，展开「补充证据检查」，补充入图、注入或外部限制的信息。过程名称可以在「过程信息」中修改，随后进入维度评价。

影响与改进线索
本轮查询与已有事实重合。对照两次工具结果，确认是否补充了独立来源或新信息，再判断是否需要优化搜索前的证据复用。
证据强度
Graph 注入与再次搜索均明确可见。Agent 本轮只输出 Tool Call，没有说明再次搜索的原因。
证据强度与归因环节的选择
明确可见
请求、输出或工具调用直接呈现了相关信息的使用过程。
有较强迹象
信息已注入，后续行动与之吻合，但输出没有明确说明引用来源。
证据不足
缺少对应请求、输出或结果，暂时无法建立完整的使用链。
归因环节
沿“信息获取 → 建图 → Graph 选择 → 注入表达 → Agent 使用”检查，选择最早出现问题的环节。过程正常选择“无明显失效”，暂不确定选择“无法判断”。

完成本步后：已整理轨迹中的关键过程。下一步根据这些过程选择维度，同一个过程可以体现多个维度。

先在第 1 步导入文件或打开练习 Case。

选择关键过程体现的维度，再评价

操作位置：右侧「维度评价」

顶部列出 8 个预设维度，可同时点亮多个。点击「＋ 自定义维度」可填写名称和说明，为当前 Case 添加新维度。点亮表示从已记录的关键过程中发现该维度存在影响可能，依据是轨迹中的实际行为与 Graph 内容，而不是任务类型。下方只显示已点亮的维度。

  1. 回顾已记录的关键过程，点亮其中体现的维度。Agent 复用了历史信息，或已有可用信息却未复用，都可以选择「长程信息复用」。
  2. 在每个已选维度中，关联支撑判断的一个或多个关键过程。
  3. 填写「是否利用」「是否产生效果」及判断依据。悬浮或聚焦字段右侧的感叹号可查看说明。
字段选择方法
点亮维度关键过程体现了该维度的影响可能，即使 Agent 最终未利用，也应选中并评价。取消点亮会隐藏表单，已填草稿保留。
是否利用充分利用 / 部分利用：相关信息得到全部或部分使用。未利用：已有可用信息被忽略。误用：错误解读信息或关系。证据不足时选无法判断。
是否产生效果正向：帮助推进任务。负向：引入错误或无效开销。无明显变化：未观察到进展差异。待验证：影响尚不明确。
证据来源每个已选维度至少关联一个关键过程。点击「查看」阅读过程中的来源、行为与影响，再写判断依据。
未发现相关维度查看轨迹后没有找到相关过程时，勾选「已查看轨迹，未发现相关维度」，在归因总结中记录结论与依据。

写出归因总结，完成并导出

操作位置：右侧「归因总结」 → 「完成标注」 → 页面右上角「导出」

  1. 在「回顾已记录的评价」中核对已选维度的利用情况、效果和判断依据。点击维度或关键过程可返回查看，左侧轨迹保持不变。
  2. 在「归因判断」中用 1–3 句话概括主要作用或问题，引用相应过程编号，并选择结论的证据强度。这部分由标注人判断，不会根据评价结果自动生成。
  3. 在「下一步改进」中选择优先改进的环节，可多选。分别写出具体改法和验证方式。没有改进建议时可以留空。
  4. 查看底部待补内容，补齐后点击「完成标注」。导出工作包留存，或导出 Markdown 分享分析。
基于已观察记录的初步总结

E01 中，Graph 已保存并注入发射日期、到达规划和飞掠次数，第 4 轮仍进行了同主题搜索。后续分析重点是这次搜索增加了哪些证据，以及这些信息如何进入最终报告。

已有证据支持归因后，再选择对应的改进环节。例如，确认信息已注入但未被利用时，选择「Agent 使用」，提出具体调整，并验证同类过程中的重复查询是否减少、必要核验是否保留。「对照与其他信息来源」用于补充同题对照或其他可用信息。

完成标注所需内容
  • 标注人和任务结果。
  • 已选维度的利用情况、效果与判断依据，或已确认未发现相关维度。
  • 主要作用或主要问题，以及结论的证据强度。
  • 每个已选维度各自关联至少一个关键过程。正向或负向评价所关联的过程需包含来源引用、实际行为、后续影响和证据强度。
导出格式用途

所有 Case · CSV汇总每个 Case 的维度评价与指标，用于后续统计。
